# Eigene UNMA-Alarmtöne

Lege hier eigene Dateien im Format PCM-WAV (`.wav`) oder Ogg Vorbis (`.ogg`)
ab. Nach dem nächsten Öffnen des UNMA-Editors erscheinen sie in der Tonliste.

Das Audioformat bestimmt nicht die Nutzungslizenz. Verwende nur eigene,
CC0-lizenzierte oder anderweitig zur Nutzung freigegebene Aufnahmen.
